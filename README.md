# «Новые выигрывают!» — сайт финального розыгрыша для трансляции

Статический сайт без сборки и сервера: открыть `index.html` в Chrome или добавить
как **Browser Source** в OBS (1920×1080). Сцена сама масштабируется под окно.

## Сценарий эфира

| Экран | Что происходит | Управление |
|---|---|---|
| 1. Главная | «Новые выигрывают!», вокруг дома (главный приз) летают призы | **Старт** / Space |
| 2. Барабан | Крутятся участники (фото, фамилия, имя, населённый пункт). Сап-борд едет по статус-бару | Воздушный змей **СТОП** / Space, либо автостоп, когда сап доедет |
| 3. Победитель | Фото, фамилия, имя, населённый пункт + конфетти и воздушные змеи | **10 запасных** / Space |
| 4–5. Запасные | Барабан на 10 ячеек, затем все 10 появляются одним списком | **Запустить барабан** / Space |

Клавиши: `Space` — следующее действие, `Esc` — на главную, `F` — полный экран, `H` — пульт ведущего.

## Честность выбора

- Победитель выбирается в момент нажатия «Стоп» через `crypto.getRandomValues` (без смещения).
- Запасные: 10 человек из всех участников, кроме основного победителя (и, по галочке, кроме победителей прошлых запусков в этой сессии).
- Один VK ID — один шанс (дубли в CSV отбрасываются).
- Каждый запуск сохраняется в браузере; в пульте кнопка «Скачать протокол» выгружает CSV: победитель + 10 запасных со ссылками на VK.

## Данные участников

По умолчанию — 400 демо-участников со случайными именами. Для эфира:

1. Добавить `apps-script/final-export.gs` в проект Apps Script бота, задать свойство `VK_SERVICE_TOKEN`, запустить `buildFinalSheet` — появится лист «Финал» (VK ID, Фамилия, Имя, Населённый пункт, Фото из VK).
2. Скачать лист «Финал» как CSV.
3. На сайте нажать `H` → «Загрузить участников».

Также подойдёт CSV прямо из листа «Участники» (колонки VK ID / ФИО / Регион), но без фото —
тогда рисуются аватары с инициалами.

## Призы

Иллюстрации призов — векторные заглушки в `js/prizes.js`. Чтобы подставить картинки из макетов:
положить PNG в `assets/prizes/` и указать путь в поле `img` нужного приза.
