# «Новые выигрывают!» — сайт финального розыгрыша для трансляции

Статический сайт без сборки и сервера: открыть `index.html` в Chrome или добавить
как **Browser Source** в OBS (1920×1080). Сцена сама масштабируется под окно.

## Сценарий эфира

| Экран | Что происходит | Управление |
|---|---|---|
| 1. Главная | «Новые выигрывают!», главный приз 1 500 000 ₽ на квартиру мечты, вокруг летают ключи, купюры, змеи | **Старт** / Space |
| 2. Барабан | Крутятся участники (фото, фамилия, имя, населённый пункт). Сап-борд едет по статус-бару | Воздушный змей **СТОП** / Space, либо автостоп, когда сап доедет |
| 3. Победитель | Фото, фамилия, имя, населённый пункт + конфетти и воздушные змеи | **10 запасных** / Space |
| 4–5. Запасные | Барабан на 10 ячеек, затем все 10 появляются одним списком | **Запустить барабан** / Space |

Клавиши: `Space` — следующее действие, `Esc` — на главную, `F` — полный экран, `H` — пульт ведущего.

## Честность выбора

- Победитель выбирается в момент нажатия «Стоп» через `crypto.getRandomValues` (без смещения).
- Запасные: 10 человек из всех участников, кроме основного победителя (и, по галочке, кроме победителей прошлых запусков в этой сессии).
- Один VK ID — один шанс (дубли в CSV отбрасываются).
- Каждый запуск сохраняется в браузере; в пульте кнопка «Скачать протокол» выгружает CSV: победитель + 10 запасных со ссылками на VK.

## Данные участников — Google Таблица

По умолчанию — 400 демо-участников. Для эфира сайт забирает список из таблицы бота:

1. Добавить `apps-script/final-export.gs` в проект Apps Script «Розыгрыш Новые Бирюзовые».
2. Свойства скрипта: `VK_SERVICE_TOKEN` (сервисный ключ VK — для имён и фото) и `FINAL_KEY` (пароль для сайта).
3. Запустить `dryRunFinal` — в журнале будет, сколько человек попадёт в финал и кто отсеян (ничего не пишет).
   Затем `buildFinalSheet` → лист «Финал» (VK ID, Фамилия, Имя, Населённый пункт, Фото, Страница VK).
   Правила отбора — константы `FINAL_*` в начале файла.
4. Развернуть → Управление развёртываниями → «Изменить» → «Новая версия». Ссылка `/exec` не меняется, приём заявок от BotMan (`doPost`) работает как раньше.
5. На сайте `H` → ссылка `/exec` + `FINAL_KEY` → «Загрузить из таблицы».

Запасной вариант — скачать лист «Финал» как CSV и загрузить файлом.
Без ключа `doGet` ничего не отдаёт: в списке персональные данные.

## Оформление

Цвета и элементы — из брендбука «Новые Бирюзовые»: Тиффани `#0ad1c9`, тёмно-бирюзовый `#0ba8a2`,
светло-бирюзовый `#d6eeec`, красный `#ef4056`, коралловый `#f26b7c`, розовые мазки, белые плашки с чёрной тенью.
Логотип, фирменный воздушный змей и сап-борд — `assets/brand/` (экспорт из макетов .ai).
Летающие предметы главной и фон — `js/decor.js`.

Маскот — нерпа в кепке-докере и косынке. Три состояния в `assets/brand/`: `mascot-wave.svg` (машет у суммы на главной),
`mascot-paddle.svg` (гребёт на сапе), `mascot-win.svg` (празднует на причале финиша). Собираются из общих частей
скриптом `python tools/mascot.py` — правки (цвета, лицо, косынка) делать там.
Сценарий поиска: доска с нерпой плывёт к причалу, после «Стоп» доска останавливается, нерпа прыгает на причал —
только тогда загорается победитель.
